# Equitorch

Equitorch is a package for constructing equivariant neural networks with Triton accelerated operators.

Author: GTML-LAB/Tong Wang

Due to several bugs in the current version of Equitorch, we temporarily copied 
and maintained a local version of the full codebase, with modifications tailored 
to the needs of TACE. Once these issues are addressed in future releases, we intend 
to decouple and remove this local copy and revert to the official implementation.
