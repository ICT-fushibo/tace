Installation
============

.. note::
   The most basic energy/force/stress predictions are essentially bug-free, but some advanced features may still contain bugs.
   Therefore, it is recommended to always use the latest commit on GitHub.
   We do not rely on any complex or heavy dependencies; since we do not use libraries that require compilation, installation should be convenient.

    It is recommended to use ``conda create`` to create a clean environment.

You can install the package in ways as described below.

Install from Source (recommended)
---------------------------------

.. code-block:: bash

    git clone https://github.com/xvzemin/tace.git
    cd tace
    pip install .

Install via pip (not recommended)
--------------------------------------------------

.. code-block:: bash

    pip install tace
